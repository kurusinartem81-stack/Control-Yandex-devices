# Control-Yandex-devices
# Важно!!! Обязательно прочитайте инструкцию, а то колонку возможно придётся перенастраивать. Для работы приложения нужен Python!
Приветствую,
Для начала работы скачайте последний релиз с главной страницы, перейдите на страницу: https://oauth.yandex.ru/client/new , затем нажмите "Для авторизации пользователей", "Перейти к созданию", верификацию проходить не надо, введите любое название для вашего приложения, прикрепите любую иконку (изображение), почта подставится сама, "Продолжить", "Веб-сервисы", в Redirect URL вставьте "https://music.yandex.ru/#access_token", "Продолжить", "Основные" выбирать не надо, в дополнительных выбирайте "Запись в любом месте на диске", "Продолжить", пролистайте вниз, "Всё верно, создать приложение", верификацию проходить не надо, пролистайте вниз, в поле "ClientID" скопируйте текст, в адресной строке вашего браузера (полоса вверху) вставьте:
https://oauth.yandex.ru/authorize?response_type=token&client_id=<СКОПИРОВАННЫЙ_CLIENT_ID>&redirect_uri=https://music.yandex.ru/#access_token
Нажмите ENTER, подтвердите вход, вас перекинет на сайт Яндекс Музыки, еще раз нажмите на адресную строку, скопируйте текст между "https://music.yandex.ru/#access_token=" и "&token_type=" , это и есть ваш "music_token" в config.json, вставьте его туда, готово, дальше легче.
После того как скачали архив выполните эти шаги:
# 1.
Разархивируйте скачанный архив в любое удобное вам место
# 2.
Откройте config.json; Поменяйте в нём все что указано
# 3.
Можете наконец-то открывать "GlagolControl.exe"
# 4.
Попробуйте подключиться к колонке, если получилось, поздравляю, вы молодец, если нет, идем дальше.

# 1. (Если не получилось)
Проверьте, точно ли вы правильно ввели ip-адрес колонки из интерфейса роутера
# 2. (Если не получилось)
Правильно ли вы ввели модель (Строка DID в днище колонки) и платформу (Надо искать в интернете) колонки, поищите в интернете кодовое имя вашей колонки и введите его в места где написано <имя вашей колонки>, платформы писать в <чип, заводское имя вашей колонки, например: yandexmini_2>, кодовые названия в <имя вашей колонки>, device_id в <модель вашей колонки, написана снизу колонки, в строке DID>, ниже приведены все известные колонки поддающиеся управлению и их кодовые названия и платформы.
# Яндекс Станция Мини 3
Кодовое название: pickle;
Пример device_id: M0PS7700010H5K;
Платформа: pickle;
# Яндекс Станция Мини 2
Кодовое название: mini2;
Пример device_id: M108PQ2009AMYG;
Платформа: yandexmini_2;
# Яндекс Станция Макс
Кодовое название: max;
Платформа: yandexmax;
# Яндекс Станция 2
Кодовое название: station2;
Платформа: station2;
# Яндекс Станция Лайт
Кодовое название: lite;
Платформа: yandexlite;
